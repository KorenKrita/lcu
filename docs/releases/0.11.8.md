# LCU 0.11.8

**Fixes Computer use approvals declined at once in the Claude app.** With 0.11.7 and the Claude app's Claude Code 2.1.304, a native-app approval in the Code tab was declined within milliseconds and no question card showed.

## Changes

- **The question card shows again in the Claude app.** With Claude Code 2.1.304 the app has no surface attached yet when an approval arrives. The `lcu-approve` mod (0.5.2) took that for a headless run and left the request to the app, which declined it. The mod now also recognizes the app from `CLAUDE_CODE_ENTRYPOINT=claude-desktop` and asks with the question card ([f5b30f0](https://github.com/amontlabs/lcu/commit/f5b30f0)).

## Behaviour changes to know about

- None beyond the fix. As in 0.11.7, the Claude app's question-card path is covered by Claude Code (now 2.1.304) run the way the app runs it, not by driving the app itself.

## Upgrading

Run `lcu update`, then restart your agents; it also refreshes the `lcu-approve` mod (a project-scoped mod needs `lcu setup --scope project` again). Your agent registrations and saved choices carry over. To go back, reinstall 0.11.7.
