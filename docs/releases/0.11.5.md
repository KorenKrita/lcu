# LCU 0.11.5

**Computer use keeps working after the ChatGPT app updates itself (macOS).** Before, an app update left every running LCU server failing each `js` call with `Sky Computer Use native pipe startup failed` until you restarted it.

## Changes

- **Restart after an app update (macOS).** When the ChatGPT app updates itself while LCU runs, the old LCU processes keep the previous build and the new Computer Use service refuses them. The Claude Code, Codex and shared relays (Pi, OMP, Hermes) now notice that exact failure after the app changed on disk, restart computer use once, and tell the model that the JavaScript session was reset and to rerun its request starting from getting the app again. The failed call is never repeated ([details](../STANDALONE-ADAPTATIONS.md)) ([559fdb9](https://github.com/amontlabs/lcu/commit/559fdb9)).
- **Capture indicator findings recorded.** The purple macOS capture indicator and the live preview come from the ChatGPT app's own preview host: the Computer Use helper streams only for a host owned by the running app. Under LCU the indicator therefore appears while the app's own helper is in use, and not when the app is closed. Investigated from [#45](https://github.com/amontlabs/lcu/issues/45) (thanks @QingLong-C) ([record](../verification/macos-pip-host-handover-2026-10-19.md)) ([c3559c8](https://github.com/amontlabs/lcu/commit/c3559c8)).

## Behaviour changes to know about

- **One call returns a "rerun your request" error after an update.** Variables from the old JavaScript session are gone; the model has to get the app again.
- **Not covered:** a harness that starts `bin/lcu` directly, without an LCU relay, still needs a manual MCP server restart after an app update.
- **Not yet driven live.** The restart is covered by fixture tests; the failure it handles was observed live on the update from ChatGPT 26.1007.71326 to 26.1013.40934, but no app update has happened since the fix.

## Upgrading

Run `lcu update`, then restart your agents. Your agent registrations and saved choices carry over. To go back, reinstall 0.11.4.
