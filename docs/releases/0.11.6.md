# LCU 0.11.6

**Fixes a race in the restart after a ChatGPT app update (macOS).** When several `js` calls were running as the restart from 0.11.5 kicked in, a call still in flight on the old server could fail with a raw `Connection closed` error instead of the "rerun your request" message.

## Changes

- **Calls the restart interrupts get the restart message.** When an app update makes the Claude Code, Codex or shared relay (Pi, OMP, Hermes) restart computer use, any call still running on the old server now gets the same "the ChatGPT app was updated, rerun your request" error as the call that triggered the restart. This also fixes an intermittent CI failure in the concurrent restart test ([c2eaf47](https://github.com/amontlabs/lcu/commit/c2eaf47)).

## Behaviour changes to know about

- None beyond the fix. As in 0.11.5, a harness that starts `bin/lcu` directly, without an LCU relay, still needs a manual MCP server restart after an app update, and the restart is covered by fixture tests, not yet by a live app update.

## Upgrading

Run `lcu update`, then restart your agents. Your agent registrations and saved choices carry over. To go back, reinstall 0.11.5.
