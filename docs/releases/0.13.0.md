# LCU 0.13.0

**Adds experimental Junie support, and makes the Windows candidate install with the current Store app.**

## Changes

- **Junie (experimental).** `lcu setup --agent junie` registers LCU with JetBrains Junie CLI on macOS and Linux. Junie's MCP client can't show approvals, doesn't send request metadata and drops server instructions, so LCU registers a relay as Junie's `lcu` MCP server and adds Junie hooks that end LCU turns and add the original instructions to the session. Setup writes `~/.junie/mcp/mcp.json` and the hooks in `~/.junie/config.json`, keeps everything else, and supports user scope only. `--approval auto` allows exactly LCU's two tools in `~/.junie/allowlist.json`. `--agent all` now includes Junie. Verified with Junie CLI 3110.7 on Linux x64 against a scripted model; desktop control on macOS, a live model and the JetBrains IDE plugin are not yet verified ([#55](https://github.com/amontlabs/lcu/issues/55), [#59](https://github.com/amontlabs/lcu/pull/59), thanks @chbndrhnns for the request).
- **Windows candidate: full install with the current Store app.** With ChatGPT 26.1021.3705.0, the Windows installer refused the app on any drive ("binding ee is reassigned…"), and `lcu setup --agent codex` then could not trust its hooks. LCU now recognises that app version's host layout, matches the long form of a short (8.3) Windows temp path, and matches the update-notice hook by the command Codex reports on Windows. A Store app installed on another drive (a junction from `C:\Program Files\WindowsApps` to an encrypted `D:\WindowsApps`) is now accepted and copied. Verified with a full `--agent codex` install and `lcu doctor` on Windows Server 2025 runners, with the app on C: and on D:. Windows remains a deferred candidate and has no archive in this release ([#57](https://github.com/amontlabs/lcu/issues/57), [#58](https://github.com/amontlabs/lcu/pull/58), [#60](https://github.com/amontlabs/lcu/pull/60), thanks @vdeng-ai for the report).

## Behaviour changes to know about

- **With Junie, app approvals are permanent until revoked.** Junie can't show LCU's per-app prompt, so for an app that isn't allowed yet, Junie is told to run `lcu apps allow <App>` itself. You approve with Touch ID or your password, and the app then stays allowed for every agent until `lcu apps revoke <App>`. Setup warns about this and asks before registering Junie.
- `lcu setup --agent all` now includes Junie. Junie registers without its CLI, so it is registered even when Junie is not installed yet.

## Upgrading

Run `lcu update`, then restart your agents. To add Junie, run `lcu setup --agent junie` and restart Junie. To go back, reinstall 0.12.1.
