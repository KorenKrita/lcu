# LCU 0.12.0

**Adds experimental DeepSeek Harness support, and fixes Hermes prompt growth, `browser status` outside Chrome, and nested `lcu` launches.**

## Changes

- **DeepSeek Harness (experimental).** `lcu setup --agent dsh` installs a native DSH plugin with DSH's own `dsh plugin add`. DSH's MCP client can't answer approvals, so the plugin asks native-app approvals on DSH's question card and ends LCU turns on DSH's `turn/end` event. It uses the `desktop` profile unless you pass `--dsh-profile`, and setup refuses that profile while DeepSeek Harness Desktop is running. `--agent all` now includes DSH. Verified live on macOS arm64 only ([#46](https://github.com/amontlabs/lcu/issues/46), [#53](https://github.com/amontlabs/lcu/pull/53), thanks @ipfans for the request and @tonyjianchina for the first attempt in [#47](https://github.com/amontlabs/lcu/pull/47)).
- **Hermes no longer grows the prompt every turn.** The original instructions now go once into each session's system prompt instead of being added to every user message, and the tool descriptors are no longer sent as text. Each turn used to add about 3 KB, even when computer use was never called ([#48](https://github.com/amontlabs/lcu/issues/48), [#51](https://github.com/amontlabs/lcu/pull/51), thanks @bigbitbox, who also pointed to `register_system_prompt_section`).
- **`lcu browser status` checks every browser.** Chrome, Edge, Brave, Opera and Vivaldi are supported, and `--browser` accepts any of them. Without `--browser`, status checks the browsers you have installed and shows any check that failed. ChatGPT 26.1013.40934 with CUA 0.0.30 is added to the tested pairs ([#49](https://github.com/amontlabs/lcu/issues/49), [#50](https://github.com/amontlabs/lcu/issues/50), [#52](https://github.com/amontlabs/lcu/pull/52), thanks @Marcussy34).
- **`lcu` works inside an app launched by LCU.** An app opened by an LCU-driven agent inherits LCU's runtime environment, and an `lcu` started inside it refused to start ("A custom Sky trusted-service override conflicts with macOS native cleanup"). The launcher now marks that environment so a nested `lcu` ignores it. The runtime also no longer receives Claude Code's own variables or Anthropic credentials ([#54](https://github.com/amontlabs/lcu/pull/54)).

## Behaviour changes to know about

- `lcu setup --agent all` now includes DeepSeek Harness. As with Pi, OMP and Hermes, add `--allow-missing` if DSH isn't installed, or it fails.
- Hermes sessions saved before this release and resumed afterwards keep their old prompt.
- A Computer Use service that started before the update keeps the old environment until it restarts.

## Upgrading

Run `lcu update`, then restart your agents. Hermes users get the new delivery from the next new session. To add DeepSeek Harness, run `lcu setup --agent dsh`. To go back, reinstall 0.11.8.
