# Live DeepSeek Harness Desktop run on macOS, 2026-10-21

This is a live check of the experimental DSH adapter for [#46](https://github.com/amontlabs/lcu/issues/46). It was run on the user's own Mac at their request. A real model drove DeepSeek Harness Desktop through LCU's plugin, and LCU's diagnostic log (`~/Library/Logs/LCU/dsh-*.jsonl`) was the oracle. **Result:** the plugin worked on 0.2.1-rc.2 on macOS arm64:
- tool calls ran;
- the native-app approval card appeared and its answer was honored;
- turn ends reached the Computer Use service for completed and stopped turns.

A text-only model could not complete a TextEdit save dialog.

## Setup

DSH Desktop was quit, then the separate-prefix `lcu setup --agent dsh` linked the generated bundle into the `desktop` profile (`lcu-computer-use`). After reopening, the log recorded `upstream_connect ok` (212 ms).

The first launch had been made by another LCU-driven agent. That DSH inherited the parent relay's runtime environment, and its own `lcu` refused to start ("A custom Sky trusted-service override conflicts with macOS native cleanup"). Without LCU's tools the model fell back to shell AppleScript, which macOS answered with an Accessibility prompt that the user declined. Relaunching DSH with `open -a` gave it a clean environment. The launcher is fixed separately on `fix/ignore-inherited-runtime-env`.

## Steps

The prompts were typed into DSH Desktop through LCU. The user answered the approval card.

| Step | Result | Evidence |
| --- | --- | --- |
| Flash: open Calculator, report the display, no input | Answered "0" | `call_start`/`call_end ok` ×2, then `turn_end Stop sky_hook live ok` |
| Flash: TextEdit plain text, `setValue`, save to `/private/tmp/lcu-dsh-flash-1.txt` | Not completed: the model looped on the save dialog (61 calls, 16 tool errors) and was stopped; no file was written | Model limit without screenshots, not an adapter fault |
| Stop during that turn | Turn interrupted | `turn_end Interrupt sky_hook live ok`; earlier `js_reset` calls each logged `Interrupt cause js_reset ok` |
| Flash: open Chess, report the window title, no moves | The DSH card "Allow Computer Use to use "Chess"?" offered Allow once / Allow for this session / Always allow / Decline. The user chose Allow for this session, and the model read "Partie 1 \| polarzero - Ordinateur" without moving | `approval_open native_app com.apple.Chess`, `approval_end accept persist session`, `turn_end Stop sky_hook live ok` |
| Pro: Calculator as above | Answered "0" in 4 s | One `js` call ok, `turn_end Stop sky_hook live ok` |

## Not verified

- Windows, Linux (CLI only; DSH has no Linux desktop), macOS x64.
