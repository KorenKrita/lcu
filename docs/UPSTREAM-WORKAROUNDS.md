# Upstream workarounds

Some LCU adaptations exist only to work around a defect in the original OpenAI runtime. Each is listed here with its upstream issue, what LCU does, where the code is, how it was verified, and the exact criterion for removing it. A workaround stays only until that criterion is met; the original implementation is preferred as soon as it behaves correctly. The general adaptation record is [STANDALONE-ADAPTATIONS.md](STANDALONE-ADAPTATIONS.md).
